# Selenium Locator Assessment

A beginner-level Selenium WebDriver practice project completed as part of my software testing training. This project focuses on identifying and locating web elements using different Selenium locator strategies.

## About the Project

This repository contains my solutions and practice code for the **Selenium Locator Assessment** provided by my teacher.

The assessment is based on the practice page from [Automation With Piyush](https://www.automationwithpiyush.com/locators.html).

The main objective of this project is to understand how Selenium WebDriver identifies web elements and how different locator strategies can be used in browser automation.

## Topics Practiced

### 1. Core Locators
- Locating elements using ID, name, class name, tag name, and link text.
- Identifying username and password fields.
- Locating buttons and links.

### 2. CSS Selectors
- Locating elements using CSS selectors.
- Using attribute-based selectors.
- Identifying specific elements based on their attributes and text-related structure.

### 3. XPath
- Writing XPath expressions to locate web elements.
- Using attribute-based and text-based XPath.
- Practising `contains()` and logical operators.
- Identifying elements based on their position and surrounding structure.

### 4. Web Table Traversal
- Locating a specific checkbox within a table row.
- Identifying a user's role based on their username.
- Locating an action button belonging to a specific user.
